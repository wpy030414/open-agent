# PRD — Open Agent 产品需求文档

## 产品定位

Open Agent 是一个**轻量级、可自托管的 Web AI 智能体平台**。它的核心价值是让个人或团队能够快速部署一个属于自己的 AI 助手，通过插件扩展能力、通过技能注入知识，并通过管理员面板灵活配置一切。

## 目标用户

- **个人开发者**：想要一个自托管的 AI 聊天界面，对接各种 OpenAI 兼容的模型 API
- **小团队**：需要一个内部的 AI 助手，能通过插件接入内部工具和数据
- **AI 应用开发者**：需要一个可快速迭代的 AI Agent 原型平台

## 核心用户场景

### 场景 1：日常 AI 对话

用户打开网页 → 输入用户名（无需密码）→ 开始与 AI 对话 → 看到流式输出的回复 → 点击建议继续追问。

### 场景 2：使用插件工具

用户提问涉及外部数据 → AI 自动调用插件工具（如搜索、查询数据库）→ 工具结果返回 → AI 基于结果生成最终回复。

### 场景 3：管理员配置

管理员点击设置图标 → 输入管理员密钥 → 修改模型配置/系统提示词 → 上传新插件/技能 → 配置立即生效，无需重启。

### 场景 4：对话管理

用户在侧边栏查看所有对话历史 → 切换对话 → 重命名或删除对话 → 创建新对话。

## 功能需求

### F1：聊天界面

- 流式输出（token 逐字显示）
- 思考过程展示（可折叠）
- 工具调用展示（调用名 + 输入参数 + 结果摘要）
- Mermaid 图表渲染
- 后续建议（3 条可点击的追问）
- 中断/取消正在进行的对话

### F2：对话管理

- 创建新对话
- 查看对话列表（按更新时间排序）
- 切换对话（加载历史消息）
- 重命名对话
- 删除对话（级联删除消息）

### F3：插件系统

- 插件清单（plugin.json）定义工具
- 插件模块（index.ts/js/mjs）实现工具逻辑
- AI 通过 function calling 自动调用工具
- 管理员可上传/卸载插件（zip 包）
- 用户可在侧边栏查看所有可用插件和工具

### F4：技能系统

- SKILL.md 文件定义技能（YAML 前置元数据 + Markdown 内容）
- 技能内容自动注入系统提示词
- 管理员可上传/卸载技能（zip 包）

### F5：管理员面板

- 密钥认证 → JWT（24h 有效期）
- 品牌配置（应用名称、Favicon）
- 模型配置（API 地址、密钥、模型名称）
- 系统提示词编辑
- 插件管理（列表/上传/卸载）
- 技能管理（列表/上传/卸载）
- API Key 脱敏显示

### F6：国际化

- 中文（默认语言）
- 英文
- 语言偏好持久化到 localStorage

### F7：主题

- 浅色/深色模式
- 跟随系统偏好
- 偏好持久化到 localStorage

## 非功能需求

### NF1：部署简单

- 单进程部署，无需外部数据库
- `pnpm build && pnpm start` 即可运行
- SQLite 单文件存储

### NF2：兼容性

- 支持所有 OpenAI 兼容的 API（包括本地模型、第三方代理）
- 支持 thinking/reasoning 内容流式输出（如 DeepSeek、Qwen）

### NF3：可靠性

- 客户端自动重试（最多 3 次，指数退避）
- SSE 15 秒心跳保活
- 60 秒空闲超时

### NF4：安全性

- 管理员密钥不暴露给前端
- JWT 认证保护管理员端点
- Zip slip 攻击防护
- 对话按用户隔离
